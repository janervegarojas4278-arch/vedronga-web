# VEDRONGA — vista previa web

Esta carpeta contiene el paquete seguro para una primera prueba pública en GitHub Pages.

- Incluye HTML, CSS, JavaScript y fotos optimizadas.
- Excluye los certificados y documentos privados de `docs`.
- Excluye los videos originales; superan el límite por archivo de GitHub y se añadirán más adelante desde un servicio de video.
- El acceso, las cuentas, los comentarios, los “Me gusta” y las publicaciones siguen siendo prototipos locales. No se comparten entre visitantes.

Para publicar con GitHub Free, sube el contenido de esta carpeta a un repositorio público y activa GitHub Pages desde la rama principal y la carpeta raíz.
